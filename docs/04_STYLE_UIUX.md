# UI/아트 스타일 가이드 v0.1 — 「SIGNAL LOST: FPV」

> 목적: 모든 개발 세션이 같은 톤으로 화면을 만들게 하는 단일 기준.
> 대원칙: **"게임 전체가 군용 단말기다."** 메뉴도, 상점도, 브리핑도 전부 야전 지휘 단말 화면처럼 보여야 한다. 예쁜 모바일 게임 UI(그라데이션, 라운드 버튼, 팝업 애니메이션) 금지.

---

## 1. 아트 디렉션

### 1.1 무드 키워드
`아날로그 CRT` / `야전 단말기` / `저전력 인광 녹색` / `무전 잡음` / `기능주의 — 장식 0`

### 1.2 컬러 팔레트 (전 화면 공통, 이 8색 밖으로 나가지 않는다)

| 토큰 | HEX | 용도 |
|---|---|---|
| `bg.base` | `#0A0F0B` | 전 화면 배경 (녹색 틴트 흑) |
| `bg.panel` | `#111A13` | 패널/카드 배경 |
| `line` | `#2E4A34` | 테두리, 구분선 (1px, 각진 모서리만) |
| `text.primary` | `#8FFFAB` | 본문, OSD (인광 녹색) |
| `text.dim` | `#4E7A5C` | 보조 텍스트, 비활성 |
| `accent.amber` | `#FFB347` | 경고, 강조, 선택 상태 |
| `accent.red` | `#FF4D4D` | 위험, 배터리 임계, 실패 |
| `text.white` | `#D8E4DA` | 제목, 수치 강조 |

- 버튼: 채우기 없음. `line` 테두리 사각형 + 텍스트. 선택 시 테두리·텍스트가 `accent.amber`로.
- 모서리 라운드 금지 (radius 0~2px). 그림자 금지. 그라데이션 금지.
- 화면 전환: 페이드 0.15초 + CRT 잔상 느낌의 짧은 노이즈 프레임 1장. 슬라이드/줌 전환 금지.

### 1.3 타이포그래피

| 용도 | 폰트 | 크기 기준(1080p) |
|---|---|---|
| OSD·수치·콜사인 | JetBrains Mono (키릴 지원 확인됨) | 28~36px |
| 본문·브리핑·버튼 | Noto Sans (언어별 서브셋) | 30~34px |
| 화면 제목 | Noto Sans Bold, 자간 +8%, 전부 대문자(라틴) | 44px |

- 숫자는 반드시 등폭 폰트 — 배터리 전압 등 실시간 수치가 흔들리면 안 됨.
- 텍스트 등장 연출: 타이핑 효과(문자당 8ms) + 커서 블록 `▮`. 무전 텍스트 전용.

### 1.4 아이콘/그래픽
- 아이콘은 1.5px 스트로크 라인 아이콘만, `text.primary` 단색.
- 장비 이미지: 3D 렌더샷 금지 → **와이어프레임/청사진 스타일 라인 드로잉** (SVG→텍스처). 격납고 화면의 시그니처. 제작 비용 낮고 톤 통일 쉬움.
- 지도: 위성사진 금지 → 등고선 + 격자(MGRS풍 좌표) 라인 맵.

### 1.5 사운드 톤 (v0.2+, 기준만 선정의)
- UI: 짧은 무전 비프(2종: 확인 800Hz / 취소 400Hz), 클릭음 금지.
- 인게임: 모터 피치(스로틀 연동), 무전 노이즈 베드(저음량 상시), 폭발은 **화면 너머 소리**(먹먹하게 로우패스) — 현장이 아니라 스피커로 듣는 전쟁.
- BGM 없음이 기본. 홈 화면만 저음 드론 앰비언트 1트랙.

## 2. 화면 흐름 (Screen Flow)

```
[Boot] → [타이틀] → [작전실(홈)] ─┬─ [캠페인 지도] → [브리핑] → [로드아웃] → [인게임] → [디브리핑] → 작전실
                                  ├─ [작전 요청(일일)] → (브리핑 생략, 간이 확인) → [로드아웃] → [인게임] → ...
                                  ├─ [격납고] (장비 관리/구매)
                                  ├─ [무전 로그] (스토리 다시보기)
                                  └─ [설정] (언어/조작 모드/어시스트)
```

- 뒤로가기(Android): 항상 한 단계 상위로. 인게임 중엔 일시정지 패널.
- 인게임 진입 로딩: 검은 화면 + "LINK ESTABLISHING…" + RSSI 게이지 차오름 (로딩을 연출로 소화).

## 3. 화면별 와이어프레임 (가로 16:9 기준)

> **세로 지원 추가** (2026-08-27): 세로로 들면 영상을 늘리지 않고 **상단 16:9 영상 +
> 하단 조종 데크**로 나눈다. 계기·무전·카메라 버튼은 데크로 내려가고, 영상 위에는
> 조준선·표적·위협 마커만 남는다. 아래 와이어프레임은 가로 기준이며, 세로는 같은 요소를
> 두 구역에 재배치한 것이다.

```
│                                         │
│         SIGNAL LOST : FPV               │  ← 로고 = 텍스트 + 노이즈 글리치 1회/4초
│         ▮ TAP TO CONNECT                │  ← 타이핑 커서 깜빡임
│                                         │
│  v0.1.0                    [언어: KO ▾] │
└─────────────────────────────────────────┘
```

### 3.2 작전실 (홈)
```
┌─────────────────────────────────────────┐

├───────────────┬─────────────────────────┤
│  [전선 상황판]  │  ▸ 캠페인: Ch.4 검은 새벽 │  ← 좌: 등고선 지도(보급 게이지 표시)
│   (등고선 지도) │  ▸ 작전 요청 (2/3 남음)   │     우: 진입 메뉴 리스트
```

```
└─────────────────────────────────────────┘
```

### 3.4 로드아웃

### 3.7 격납고 (상점 겸용)
- 좌: 장비 리스트(티어별 탭 T1~T5, 미해금은 `text.dim` + 자물쇠 없이 "티어 부족" 텍스트만).
- 우: 선택 장비의 청사진 드로잉 + 스펙 비교(현재 장착 대비 ▲▼ 화살표).
- 구매 버튼: `[승인 요청 — 320 SP]` — "구매"가 아니라 "보급 승인" 어휘. 세계관 어휘 통일(아래 5장).

### 3.8 작전 계획 (타격 편대 — GDD 4.7)
```
┌─────────────────────────────────────────┐
│ 작전 계획 — 심장부 타격        경계도 ▓░░░│
├──────────────────┬──────────────────────┤
│  [표적 의존 그래프] │ 편대 편성 (5)         │
│   ┌───┐            │ 1 [정찰기  ▾] 마브카-R │
│   │레이더│──┐        │ 2 [중계기  ▾] 브릿지  │
│   └───┘  ▼        │ 3 [타격/HEAT ▾]       │
│   ┌───┐ ┌─────┐   │ 4 [타격/소이 ▾]       │
│   │ EW │ │미사일│   │ 5 [ + 비워둠 ]        │
│   └───┘ └──┬──┘   │                      │
│      ?  ──▶│본청│   │ ≡ 드래그로 출격 순서   │
├──────────────────┴──────────────────────┤
│ 예상 소요 4소티      [1번기 출격 ▸]       │
└─────────────────────────────────────────┘
```
- 노드: 파괴됨 = `text.dim` + 취소선, 미확인 = `?` 표기(정찰로만 해금).
- 라인은 1px 직선/직각 꺾임만 (곡선 금지). 의존 방향은 화살표 `▶`.

### 3.9 소티 간 화면 (연속성의 생명선 — 3초 내 재진입)
```
┌─────────────────────────────────────────┐
│ 1번기 소티 종료 — 레이더 파괴 ✓          │
│ ─ 전장: 레이더 ✓ / EW ─ / 본청 ─        │
│ ─ 경계도 ▓▓░░ (상승)                    │
│ ─ 잔여 편대 ▮▮▮▮□                       │
│ ⚠ 이동식 레이더 전개까지 15초            │  ← 압박 정보는 accent.amber
│           [2번기 즉시 출격 ▸]            │  ← 기본 포커스. 대기 유도 금지
└─────────────────────────────────────────┘
```
- **연출 총량 2초 이내.** 여기서 리듬이 끊기면 편대 시스템 전체가 죽는다.

### 3.10 청사진 전개 (보급 승인 연출 — GDD 6.5.2)
- 3초 시퀀스: 컨테이너 도착음 → 청사진 라인 스트로크 애니메이션(SVG path draw) → 스펙 수치 타이핑 → `승인 완료` 도장(amber, 회전 없이 스탬프 압인 1프레임).
- 2회차부터 스킵 옵션. 화면 전체를 덮되 배경은 `bg.base`.

### 3.11 작전실 — 밤사이 무전 (세션 시작 훅)
- 3.2 작전실 상단바 아래에 미읽 무전 배너: `▸ 미확인 통신 2건` (amber 점멸 1회/2초, 소리 없음).
- 탭 시 무전 로그 오버레이 → 읽으면 SP 지급 + 배너 소멸. **모달 강제 금지** — 무시하고 바로 출격 가능해야 함.

## 4. 공통 컴포넌트 규격

| 컴포넌트 | 규격 |
|---|---|
| 버튼 | 높이 96px(터치 최소 88px 준수), line 테두리, 텍스트 중앙, 눌림 = 배경 `bg.panel` + 테두리 amber |
| 리스트 행 | 높이 112px, 좌 텍스트/우 수치, 구분선 `line` |
| 토스트(무전) | 하단 중앙, 1줄, 3초, 타이핑 효과, 최대 1개 큐잉 |
| 다이얼로그 | 화면 중앙 사각 패널, 제목+본문+버튼 2개(좌 취소/우 확인), 배경 딤 70% |
| 게이지 | 블록 문자 스타일 `▓▓▓░░` 또는 1px 바, 라운드 금지 |
