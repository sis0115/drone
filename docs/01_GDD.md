## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 미드코어 FPV 드론 전쟁 시뮬레이터 (미션 기반) |
| 한 줄 컨셉 | "저화질 카메라 너머의 전쟁 — 당신은 드론 조종사다" |
| 핵심 감성 | 아날로그 노이즈 낀 흑백/열화상 FPV 화면, 신호가 끊길 듯한 긴장감, 확인 킬 후 정적 |
| 세션 길이 | 미션당 3~7분 (모바일 최적) |
| 차별점 | ① 실전 기반 미션 시나리오 ② 저화질 카메라 연출 = 몰입 + 저비용 그래픽 ③ "사령부 쿼터 → 보급 포인트 → 장비 업그레이드" 진행 시스템 |
| 세계관 | 실제 전쟁을 모티프로 하되 국가명/부대명은 추상화 ("동부 전선", "북부 연합군" 등) — 스토어 심사 리스크 회피 |

## 2. 코어 루프

```
[브리핑] 사령부 미션 수신 (목표·제약·보상 명시)
   ↓
[장비 선택] 드론 기체 + 페이로드 + 모듈 (배터리/카메라/안테나)
   ↓
[출격] 이륙 → 저화질 FPV 화면으로 침투
   ↓
[수행] 정찰 / 타격 / 회피 / 귀환 (미션별 상이)
   ↓
[평가] 확인 킬·정찰 정보·기체 회수 여부 → 보급 포인트(SP) 산정
   ↓
[보급] SP로 상위 장비 언락 / 소모품 보충
   ↓
[승급] 사령부 신뢰도 상승 → 상위 티어 미션 개방
```

**감정 곡선 설계**: 이륙(고요) → 침투(긴장 상승) → 목표 발견(집중) → 타격 직전 최고조 → 화면 노이즈 → 신호 두절(암전) → 정찰 드론 시점으로 결과 확인(카타르시스 or 허탈).

## 3. 미션 디자인 (9대 시나리오)

각 미션은 **[목표] / [제약(게임성)] / [실패 조건] / [플레이어 스킬]** 구조로 설계.

### M1. 비행장 습격 — "값비싼 새들"
- **목표**: 주기장에 계류된 전략폭격기/수송기 타격. 기체별 가치 차등 (폭격기 > 수송기 > 전투기 모형(더미)).
- **제약(게임성)**:
  - **더미 식별**: 일부는 목재 더미(디코이). 저화질 화면에서 열화상 전환으로 엔진 열 확인해야 진짜 판별 → 카메라 업그레이드의 존재 이유.
  - **타격 부위 판정**: 연료탱크/날개 연결부 명중 시 1발 격파, 동체 명중은 손상만. 실제 전례 반영.
  - 대공포/방해전파 구역이 레이더 맵에 붉은 원으로 표시 — 우회 경로 설계 필요.
- **실패 조건**: 진입 전 격추, 배터리 소진, 더미만 타격.
- **스킬**: 정찰-식별-우선순위 판단.

### M2. 들판의 추격전 — "강철 사냥"
- **목표**: 개활지 기동 중인 장갑차 종대 추격 타격.
- **제약(게임성)**:
  - **이동 표적 리드샷**: 장갑차 속도 + 바람을 계산해 요격점 조준. 속도 업그레이드가 직접 체감되는 미션.
  - **회피 기동 AI**: 발견당하면 지그재그 기동 + 병력 하차 후 소화기 대공사격.
  - **연료 게이지 압박**: 추격전이라 배터리 소모 2배속 — 놓치면 재추격 불가.
- **실패 조건**: 배터리 소진, 표적 이탈(맵 밖).
- **스킬**: 고속 조종, 예측 조준.

### M3. 숨은 포탑 — "눈이 되어라" (정찰 미션)
- **목표**: 위장망 아래 숨은 적 전차 3대 위치 식별 → 좌표 전송 → 아군 포격 유도 → 피해 평가(BDA).
- **제약(게임성)**:
  - **직접 타격 불가**. 정찰 드론이라 무장 없음 — "죽이지 않고 이기는" 미션.
  - 위장 전차는 육안으론 수풀. **열화상/궤도 자국/포신 그림자** 3종 단서 조합으로 식별.
  - 좌표 전송 시 사진을 찍어야 하며, **고도가 낮을수록 정밀도↑ 발각 위험↑** 트레이드오프.
  - 포격 낙하 후 재진입해 격파 확인 — 미확인 시 SP 50%만 지급.
- **실패 조건**: 격추, 오인 좌표(민가·더미) 전송 시 페널티.
- **스킬**: 관찰력, 위험 관리.

### M4. 트럭의 새벽 — "심장부 타격" (스페셜 미션)
- **목표**: 적 종심 깊숙이 잠입한 트럭 컨테이너에서 드론 편대 출격 → 전략 시설(레이더 기지/유류고) 동시 타격.
- **제약(게임성)**:
  - **멀티 드론 순차 조종**: 4~5기를 릴레이로 조작 (→ 4.7 타격 편대 시스템의 대표 미션). 표적 의존 그래프(레이더→미사일 진지→본청)를 스스로 공략 순서로 풀어야 함.
  - **발각 타이머**: 첫 폭발 후 기지 경계 태세 격상 — 시간이 갈수록 대공 화망 증가.
  - **원거리 신호 열화**: 시설에서 멀어질수록 화면 노이즈 증가, 입력 지연 0.2~0.5초 발생 — 최상급 중계 모듈로 완화.
- **실패 조건**: 4기 전멸 전 주목표 미파괴.
- **스킬**: 자원 배분, 순서 전략. → **챕터 보스급 미션**, 클리어 시 대형 보상.

### M5. 실 끊기 — "거미줄 사냥꾼"
- **목표**: 재밍이 안 통하는 적 광섬유 드론의 **케이블을 역추적**해 조종 거점 타격, 또는 비행 중인 광섬유 드론의 선을 커터 드론으로 절단.
- **제약(게임성)**:
  - 광섬유 케이블은 저화질 화면에선 거의 안 보임 — **햇빛 반사각/눈 쌓인 지면**에서만 반짝임. 시간대·날씨가 난이도 변수.
  - 케이블 추적 중 적 FPV가 역으로 아군 기체를 노림 — **쫓는 자가 쫓기는 구조**.
  - 절단 미션은 근접 정밀 조종(선에 프로펠러 얽히면 아군 추락).
- **실패 조건**: 케이블 로스트, 아군 기체 얽힘 추락.
- **스킬**: 추적, 정밀 근접 기동.

### M6. 지하의 침묵 — "우편 배달"
- **목표**: 수류탄/소형 폭탄을 투하 장착하고 참호·방공호 입구·환기구에 정확히 투입.
- **제약(게임성)**:
  - **투하 물리**: 낙하물은 관성 + 바람 영향 — 호버링 투하는 쉽지만 대공사격에 노출, 이동 투하는 안전하지만 어려움.
  - 방공호 입구는 좁고 각도 제한 — **진입 경로 퍼즐** 성격.
  - 실내 진입형(FPV 직접 돌입)은 GPS 두절 + 좁은 통로 + 조명 없음(야시 카메라 필수).
- **실패 조건**: 투하 실패 3회, 통로 충돌.
- **스킬**: 정밀 투하, 실내 기동.

### M7. 산탄총의 사정거리 — "50미터의 죽음"
- **목표**: 대드론 산탄총 분대가 경계하는 구역의 표적 타격.
- **제약(게임성)**:
  - 산탄총 유효사거리 ~50m를 **위험 반경 시스템**으로 구현: 반경 진입 시 화면 가장자리 경고 + 사수가 총구를 드는 애니메이션 = 회피 타이밍 텔레그래프.
  - **고고도 접근 후 급강하** or **초저공 지형 은폐 기동** 두 가지 공략 루트.
  - 피탄 시 즉사가 아니라 **프로펠러 손상 → 조종 불안정(한쪽으로 쏠림)** 상태로 마지막 돌입 기회 부여 — 드라마 연출.
- **실패 조건**: 완파, 표적 미달성.
- **스킬**: 타이밍, 접근 각도 설계.

### M8. 검은 새벽 — "요격전" (신규, 기지 방공)
- **목표**: 야간에 아군 기지·발전 시설로 몰려오는 적 자폭 드론 편대를 요격 드론으로 공중 격추.
- **제약(게임성)**:
  - **드론 대 드론 공중전**: 열원 추적 시점(열화상 화면에 적 기체가 흰 점으로) → 접근 → 충돌 요격. 요격 타이밍 판정(너무 빠르면 빗나감, 늦으면 시설 피해).
  - **웨이브 방어 형식**: 3~5파, 파마다 침투 각도·고도 변화. 시설 체력 게이지 존재.
  - 아군 대공 사격 구역 존재 — 진입 시 아군 오사 위험(식별 시스템 학습).
- **실패 조건**: 시설 체력 0, 요격기 전멸.
- **스킬**: 공중 요격 타이밍, 3차원 추적. → **웨이브 구조라 작전 요청(반복 축) 재활용 최적.**

### M9. 도로 사냥꾼 — "병참 봉쇄" (신규, 보급 차단)
- **목표**: 중계 드론을 상공에 띄우고 장거리 기체로 적 후방(전선 뒤 30km+) 보급로를 배회, 연료 트럭·탄약 수송·보급 종대를 선별 요격.
- **제약(게임성)**:
  - **표적 가치 판단**: 연료차(대박, 유폭) > 군용 트럭 > 지휘 차량 > 승용차(민간 가능성 — 오폭 시 대형 SP 페널티 + 신뢰도 하락). 저화질 화면에서의 차종 식별이 곧 게임.
  - **배회 연료 관리**: 체공 시간 내 "기다림 vs 아무거나 침" 딜레마 — 도로에 표적이 랜덤 간격으로 등장.
  - **중계기 2기 운용**: 중계 드론이 격추되면 신호 열화 — 중계기 위치 선정이 전략.
  - 미션 성공 누적 시 **전선 상황판의 적 보급 게이지가 감소** → 후속 미션(M1 등) 난이도에 실제 반영 (방공망 후퇴).
- **실패 조건**: 체공 종료까지 유효 표적 0, 민간 차량 오폭 2회.
- **스킬**: 식별·인내·가치 판단.

## 4. 공통 제약 시스템 (게임성의 뼈대)

모든 미션에 적용되는 4대 자원/위협. **업그레이드는 전부 이 4개를 완화하는 방향**으로 설계 → 아이템 가치가 직관적.

| 시스템 | 메커닉 | 대응 업그레이드 축 |
|---|---|---|
| 🔋 배터리 | 시간 + 기동 강도에 따라 소모. 잔량 30% 이하 시 화면에 저전압 경고 깜빡임 | 배터리 용량 / 효율 모터 |
| 📡 전자전(EW) | 재밍 구역 진입 시 노이즈↑ 입력 지연↑, 심하면 신호 두절(수 초간 조종 불가) | 주파수 호핑 / 중계기 / 광섬유(재밍 무효) |
| 🌬️ 바람 | 기체가 흐르고 투하물이 빗나감. 돌풍은 화면 흔들림으로 예고 | 자이로 안정화 / 대형 프레임 |
| 👁️ 시야 | 기본 아날로그 480p 흑백. 야간/연막/위장 판별 불가 | 디지털 HD / 열화상 / 야시(스타라이트) |

**신호 두절 연출(시그니처)**: 격추·자폭 순간 화면이 컬러바→노이즈→"SIGNAL LOST" 정지 화면. 이후 상공 정찰 드론 시점으로 전환해 결과 확인.

### 4.5 위협 카탈로그 (실패 요소 설계)

자원 제약(4대)이 "수동적 압박"이라면, 위협은 **"능동적으로 플레이어를 죽이러 오는 것"**. 5계열 분류:

| 계열 | 위협 | 메커닉 (예고 → 대응) |
|---|---|---|
| **A. 능동** | A1 산탄총 보병 | 50m 위험 반경, 총구 드는 모션 = 텔레그래프 → 급강하/우회 |
| | A2 기관총 대공 | 첫 점사는 빗나가는 예광탄(경고) → 궤적 보고 축선 이탈 |
| | A3 적 요격 드론 | 레이더 경보 → 추격전, 저공·장애물로 따돌리기 |
| | A4 대공포 구역 | 고도 40m+ 진입 시 플랙 작렬 → 저공 침투 강제 |
| **B. 전자전** | B1 재밍 돔 | signalQuality 감쇠 (기존 4대 제약과 연동) |
| | B2 GPS 스푸핑 | 나침반 회전·미니맵 좌표 왜곡 → 지형지물 눈대중 항법 |
| | B3 신호 역추적 트럭 | 한 구역 60초+ 체공 시 역추적 게이지 → 만료 시 "조종소 피격" 즉시 실패. 이동하며 싸우게 만드는 장치 |
| **C. 환경** | C1 전선줄/와이어 | 저화질 화면에서 거의 안 보임 — 저공 침투의 대가. 전신주 위치로 추론 |
| | C2 비 | 렌즈 물방울 + 열화상 대비 저하 |
| | C3 야간/안개/연막 | 시야 제약 (기존 4대와 연동) |
| **D. 기만** | D1 열원 디코이 | 모닥불·히터로 위장한 가짜 열원 → 형상+열 이중 확인 필요 |
| | D2 미끼 트랩 | 일부러 노출된 "쉬운" 표적 주변에 A1/B1 매복 — "너무 쉬우면 의심하라" 학습 |
| | D3 민간 식별 | 오폭 대형 페널티 (M9) |
| **E. 기체** | E1 프로펠러 손상 | 피탄 시 즉사 대신 쏠림 조종 → 마지막 돌입 기회 |
| | E2 저온 감퇴 | 겨울 맵 배터리 -25% |
| | E3 광섬유 얽힘 | 급기동 시 자기 선에 걸림 (M5, T5 기체 리스크) |

**설계 규칙 (위협 목록보다 중요)**
1. **모든 위협은 예고된다** — 예고 없는 죽음은 분노, 예고된 죽음은 "내 실수". 최소 0.5초 텔레그래프 의무.
2. **스킬 대응 + 장비 대응 이중화** — 장비는 필수가 아니라 "편해지는 것". 파밍 강요 방지.
3. **미션당 위협 2~3개 상한** — 4개 이상은 난이도가 아니라 소음. 차수 상승 = 위협 교체/추가로 표현.
4. **실패가 가르친다** — 격추 시 디브리핑에 원인 분석 1줄 자동 생성: "격추 원인: 산탄총 / 접근 고도 12m — 권장 40m 이상". 재도전 동기의 핵심 장치.

### 4.7 타격 편대(Strike Package) — 연속 작전 시스템

**문제의식**: 1기 자폭 = 미션 종료 구조는 "폭격 한 번"으로 끝나 전략성이 없다. 대형 작전은 **여러 기체를 순차 운용하며, 무엇을 먼저 부술지 스스로 결정**하게 만든다. M4(트럭의 새벽)의 릴레이 개념을 독립 시스템으로 승격 — M1·M4·M9 및 모든 3차수 미션에 적용.

#### 4.7.1 구조

```
[작전 계획 화면] 편대 편성 (기체 3~5기, 각각 역할·장비 개별 지정)
   ↓
[1소티] 기체 #1 출격 → 목표 선택 → 성공/실패 → 자폭 또는 귀환
   ↓  (결과가 전장 상태에 영구 반영 + 획득 정보 계승)
[2소티] 기체 #2 출격 — 앞선 결과에 따라 난이도·가용 경로 변화
   ↓  … 편대 소진 또는 주목표 파괴까지 반복
[작전 종합 평가] 소티별 성과 합산, 남은 기체 = 보너스 SP
```

**핵심**: 각 소티는 독립 미션이 아니라 **하나의 작전을 구성하는 단계**. 중간에 나가도 진행 상태 저장(모바일 세션 특성 대응 — 소티 단위 3~5분).

#### 4.7.2 표적 의존 관계 (전략성의 실체)

목표들이 서로를 보호하는 **의존 그래프**로 배치된다. 순서를 잘못 잡으면 진입조차 못 한다.

```
[방공 레이더]  ──보호──▶ [대공 미사일 진지] ──보호──▶ [지휘 본청(주목표)]
      │                        │
      └──보호──▶ [전자전 안테나] ──방해──▶ (아군 전 기체 신호 품질)
                        │
                   [발전 시설] ──전력──▶ (레이더 + EW 동시 정지, 단 30초 후 예비 발전기 가동)
```

- **레이더 파괴 전**: 고고도 접근 시 즉시 요격. 초저공 침투만 가능(= 와이어·지형 위험 노출).
- **EW 안테나 파괴 전**: 전 기체 signalQuality 0.4 고정 — 조작 지연으로 정밀 타격 곤란.
- **주목표(본청)**: 벙커 구조라 **성형작약 2발 연속 명중** 또는 소이탄 필요 → 페이로드 배분을 계획 단계에서 미리 결정해야 함.
- **발전 시설 루트**: 하이리스크 지름길. 파괴 시 레이더+EW가 동시에 30초간 정지 → 그 안에 2기를 밀어넣는 러시 전략 성립. 실패 시 편대 하나를 헛되이 잃음.

→ 정답 루트가 2~3개 존재하도록 설계. "레이더부터 안전하게" vs "발전소 도박" vs "EW 먼저 잡고 정밀타격" 중 선택.

#### 4.7.3 기체 역할 분담 (편성의 재미)

| 역할 | 소모 여부 | 기능 |
|---|---|---|
| **정찰기** | 귀환 가능 | 표적 위치·방공 배치 사전 노출. 소모 안 하고 정보만 얻는 소티 |
| **중계기** | 체공 유지 | 상공 배회하며 후속 기체 signalQuality +. **격추당하면 남은 편대 전체가 지연 페널티** |
| **타격기(HEAT)** | 자폭 | 장갑·벙커용 |
| **타격기(소이)** | 자폭 | 유류·항공기·안테나용 |
| **커터/전용기** | 자폭 | 광섬유 절단, 특수 표적 |

편대 5기 = 슬롯 5개. 정찰 2기를 넣으면 안전하지만 타격력 부족, 타격기 5기는 눈먼 돌격. **편성 자체가 전략 선택.**

#### 4.7.4 연속성 장치 (소티 간 계승)

| 계승 요소 | 내용 |
|---|---|
| **전장 상태** | 파괴된 것은 영구 파괴. 켜진 경계 태세는 유지 |
| **정보** | 앞 기체가 본 표적은 미니맵에 마킹 유지(정찰의 가치) |
| **경계 게이지** | 폭발마다 상승 → 대공 사격 밀도·수색 드론 출현 증가. **시간을 끌수록 불리** |
| **적 대응 행동** | 레이더 파괴 시 이동식 레이더가 15초 후 전개(= 유예 시간 안에 다음 단계 진행 필요) |
| **손실 누적** | 격추된 기체는 그 작전에서 복구 불가. 남은 기체 수 = 실질 체력 |

#### 4.7.5 실패 조건과 보상 곡선

- **작전 실패**: 편대 전멸 + 주목표 미파괴. → 다음 시도 시 적 경계 태세 1단계 상승(재도전 난이도↑, 대신 정찰 정보는 유지되어 실질 진행감 부여).
- **부분 성공 인정**: 주목표 실패라도 레이더·EW 파괴분은 SP 지급 + **다음 시도에 파괴 상태 일부 유지**(24시간 내 재출격 시). 완전 리셋 방지 = 이탈 방지.
- **★3 조건**: 주목표 파괴 + 기체 2기 이상 잔존 → "최소 자원으로 최대 성과" 최적화 플레이 유도. 리플레이 동기의 핵심.

#### 4.7.6 UI 요구사항 (스타일 가이드 반영 필요)

- **작전 계획 화면**(신규): 좌측 표적 의존 그래프(노드-라인, 미확인 노드는 `?` 표기), 우측 편대 슬롯 5칸 편성. 출격 순서 드래그 정렬.
- **소티 간 화면**: 전장 상태 요약(파괴 ✓ / 경계 게이지 / 잔여 기체) + "다음 기체 출격" — 3초 내 재진입 가능하게. **여기서 리듬이 끊기면 시스템 전체가 죽는다.**
- HUD에 잔여 편대 표시: `FLEET ▮▮▮□□`

### 5.1 기체 (프레임)

| 티어 | 명칭 (모티프) | 특성 |
|---|---|---|

| T5 | **위도우 스레드** (광섬유 FPV) | 재밍 완전 무효, 케이블 길이=사거리 제한, 선 얽힘 리스크 |

### 5.2 모듈 (슬롯 3개: 카메라 / 동력 / 링크)

| 슬롯 | T1 → T5 진행 예시 |
|---|---|
| 카메라 | 아날로그 흑백 480p → 아날로그 컬러 → 디지털 HD → **열화상 "레드아이"** → 열화상+야시 듀얼 |

| 링크 | 기본 안테나 → 지향성 안테나 → 주파수 호핑 → **공중 중계기 "브릿지"**(2기 운용) → 광섬유 릴 |

### 5.3 페이로드 (소모품 — SP로 보충, 과금 아님)

성형작약(대장갑) / 파편탄(대인·대공) / 수류탄 투하기 / 소이탄(유류고·항공기 특효) / 연막(탈출용).

**설계 원칙**: 미션 유형별 최적 조합이 다르게 → 브리핑 읽고 로드아웃 고민하는 재미. 예) M1 비행장 = 소이탄+열화상, M7 산탄총 = 레이싱 모터+파편탄.

## 6. 진행 시스템 — 2축 구조 (몰입 핵심)

실제 우크라이나의 킬 포인트 보급 제도(격파 실적 → 포인트 → 장비 상점)를 게임화. 콘텐츠는 **캠페인(일회성 도전)**과 **작전 요청(반복 파밍)** 2축으로 분리하고, 장비가 두 축을 연결한다.

### 6.1 축 1 — 캠페인 (차수 해금형, "처음 하는 재미")

7대 테마(M1~M7)를 각각 **3차수**로 구성. 차수가 오를수록 적이 세지는 게 아니라 **4대 제약(배터리·EW·바람·시야)이 하나씩 추가**되는 방식 — 맵 재활용 + 파라미터 조정 위주라 제작 비용이 낮다.

| 예시: M2 추격전 | 구성 | 신규 제약 |
|---|---|---|
| 1차 | 들판, 트럭 종대(느림·비무장) | 없음 (기본) |
| 2차 | 진창길, 장갑차 + 하차 보병 대공사격 | 바람 |
| 3차 | 설원 야간, 재밍 구역 통과 후 요격 | 시야 + EW |

- **별 평가(★1~3)**: ★1 클리어 / ★2 기체 회수 귀환 / ★3 보너스 목표(노히트, 시간 제한 등).
- **해금 조건**: 다음 테마 개방 = 누적 별 수. 차수별 상위 난이도는 특정 장비 없이는 사실상 공략 불가하게 설계 (예: 3차수 야간 = 열화상 필수) → 축 2로 자연 유도.
- 클리어 보상은 SP + **최초 클리어 한정 장비 설계도**(해당 티어 장비 상점 등록).

### 6.2 축 2 — 작전 요청 (반복형, "SP 버는 일상")

매일 갱신되는 **랜덤 생성 계약 미션 3개**. 기존 맵 + 적 배치 셔플로 생성(콘텐츠 제작 비용 ≈ 0).

- 형식: "북부 구역 장갑차 2대 격파 — 보상 SP 120", "교량 정찰 사진 3장 — SP 80" 등.
- 난이도·보상은 현재 신뢰도 티어에 스케일링 → 상위 티어일수록 파밍 효율 상승.
- 리워드 광고 접점: 요청 1회 리롤 / 보상 1.5배 부스트.

### 6.3 장관 쿼터 & 보급 경제 (두 축 공통)

- **신임 혁신 장관 캐릭터**: 젊은 장관이 부임하며 "실적 기반 보급 시스템" 도입 — 튜토리얼 내러티브로 자연스럽게 설명. 브리핑/무전 텍스트로만 등장(성우·모델링 비용 절감).
- **주간 쿼터**: "이번 주 확인 격파 10건" — 캠페인·작전 요청 실적 합산. 달성 시 SP 보너스 + 신뢰도 상승. 주간 리텐션 루프 담당.
- **확인 킬 시스템**: 격파 후 정찰 드론으로 촬영·전송해야 100% 인정. 미확인 50% — 리스크 테이크 유도.
- **SP(보급 포인트)**: 장비 언락·소모품 구매 화폐. 표적 가치 차등(전략폭격기 >> 트럭).
- **신뢰도 티어 (T1~T5)**: 상위 캠페인 차수·장비·작전 요청 등급 개방. 실패해도 하락 없음(모바일 이탈 방지), 대신 기체 손실 시 SP 차감 → "회수 귀환"에 인센티브.

### 6.4 순환 구조

```
캠페인 차수에서 막힘 (예: 3차수 야간 → 열화상 필요)
   ↓
작전 요청 돌며 SP 파밍 (일일 루프)
   ↓
열화상 구매 → 캠페인 돌파 → 신뢰도 티어 상승
   ↓
작전 요청 보상 등급 상승 → 파밍 효율↑ → 다음 장비
```

"막히면 파밍"이 강제가 아닌 자연스러운 순환이 되도록, 캠페인 필수 장비 가격은 **작전 요청 3~5일 분량 SP**로 밸런싱.

### 6.5 보상 심리 설계

**대전제 — 팡파레 금지, 세계관 내 보상.** 스타일 가이드가 "축하합니다!"·반짝이·코인 이펙트를 금지하므로, 보상은 **연출의 크기가 아니라 의미의 무게**로 전달한다. 레벨업 대신 장관의 승인 통지, 이펙트 대신 무전 한 줄, 팡파레 대신 유폭 화염. 절제가 오히려 보상을 귀하게 만든다는 원칙.

#### 6.5.1 보상 타이밍 맵 (초 단위 설계)

| 시점 | 장치 | 원리 |
|---|---|---|
| 앱 실행 후 3초 | **밤사이 무전 2건** 도착 알림 (쿼터 정산·전선 변화·장관 통지) | 세션 시작 훅 — 접속 즉시 읽을 거리 |
| 미션 중 상시 | 표적 발견 시 자동 마킹음 + 무전 반응 | 탐색 보상 |
| 명중 순간 | 화면 백색 플래시 2프레임 + 저역 폭발음 + 햅틱 | 즉시 감각 보상 |
| 명중 +2초 | 유폭 발생 여부 판정(가변) — 탄약차면 2차 폭발 + 보너스 무전 | **가변 보상**(핵심) |
| 격파 +5초 | 고스트의 확인 무전 → 그때 SP 확정 | 지연 보상, 기대 구간 |
| 디브리핑 | 항목별 타이핑 + SP 카운트업 틱 사운드 | 누적 시각화 |
| 보급 승인 직후 | **청사진 전개 연출**(3초) | 획득 순간의 의식화 |
| 티어 승급 시 | 장관 직접 무전 + 격납고 신규 항목 `NEW` 표기 | 사회적 승인 + 다음 목표 제시 |

#### 6.5.2 5대 장치 상세

**① 세션 시작 훅 — "밤사이 무전"**
접속 시 작전실 상단에 미읽 무전 1~3건. 내용은 ⓐ 주간 쿼터 진행 정산 ⓑ 전선 상황 변화(내 지난 격파의 결과) ⓒ 장관/바딤의 플레이버. 읽으면 소액 SP(20~50) 지급 — 접속 자체에 보상.
→ **원칙**: 로그인 보너스를 "출석 체크"가 아니라 "부재중 통신 확인"으로 위장. 세계관 유지 + 습관 형성 동시 달성.

**② 획득 의식 — "청사진 전개"**
보급 승인 시 즉시 인벤토리 반영 금지. 3초 연출: 보급 컨테이너 도착음 → 청사진 라인이 한 획씩 그려짐 → 스펙 수치가 타이핑되며 채워짐 → `승인 완료` 도장. 스킵 가능(2회차부터 자동 스킵 옵션).
→ 언박싱 도파민을 세계관 어휘로 구현. 라인 드로잉이라 제작 비용도 낮음.

**③ 니어미스 피드백 — "아깝다"의 설계**
성공보다 재도전을 만드는 건 **아까운 실패**. 판정과 반응을 명시적으로 구현:
- 착탄 거리 1~3m: 무전 "빗나갔다. 1미터. …1미터였어."
- 표적 격파했으나 확인 실패: "격파는 봤다. 사진이 없을 뿐이지. 아깝군."
- 주목표 파괴 직전 격추: 디브리핑에 잔여 체력 게이지 표시 — 얼마나 아까웠는지 시각화
- 실패 원인 1줄 자동 분석(4.5 규칙 4)과 세트로 작동 → "다음엔 된다" 확신 생성

**④ 스트릭 — "연속"의 3종**
| 종류 | 조건 | 보상 |
|---|---|---|
| 연속 확인 킬 | 미션 내 확인 3연속 | SP +15%, 화면 좌상단 `STREAK ×3` (녹색 단색, 이펙트 없음) |
| 무손실 연속 | 기체 손실 없이 3미션 | 보급 보너스 + 바딤 인정 무전 |
| 접속 연속 | 일 단위 | 3·7·14일에 소모품 지급. **끊겨도 페널티 없음** (죄책감 유도 금지 — 건강한 습관 설계) |

**⑤ 사운드 보상 (v0.2 사운드 작업 시 최우선 구현)**
도파민의 절반은 청각. 우선순위 3종: ⓐ 확인 킬 확정음(짧은 2음 상승 비프) ⓑ SP 카운트업 틱 ⓒ 유폭 저역 임팩트. BGM보다 이 3개가 먼저다.

#### 6.5.3 금지 사항 (건강한 설계 유지)

- ❌ 시간 제한 상술(FOMO 타이머), 접속 끊김 페널티, 죄책감 유발 문구
- ❌ 확률형 유료 상자 — 장비는 SP로만(P2W 금지 원칙과 동일선상)
- ❌ 세션 연장을 강요하는 미완료 보상(하루 목표는 20~30분 내 달성 가능하게)
- ✅ 판단 기준: "내일도 하고 싶게 만드는가" ○ / "오늘 못 끄게 만드는가" ✕

### 6.6 기체 재고 & 보급 리듬 (소프트 게이트)

**설계 원칙: 접근을 막지 않는다. 효율만 제한한다.**
하드 스태미나(플레이 자체를 차단)는 6.5.3 금지 사항 및 11장 P2W 금지와 충돌하고, 밀리터리 코어 유저층의 이탈·리뷰 폭탄 요인이며 Steam 확장 시 치명적. 대신 **기체 재고제**를 쓴다.

#### 6.6.1 구조

| 티어 | 보유 상한 | 입고 시간(1기) | 비고 |
|---|---|---|---|
| **T1 스패로우-7** | **무제한** | — | 야전 조립 라인. **언제나 출격 가능(게이트 없음)** |
| T2 | 6기 | 20분 | |
| T3 | 4기 | 45분 | |
| T4 | 3기 | 90분 | |
| T5 | 2기 | 3시간 | 광섬유 등 최상급 |

- **회수 귀환 = 정비 5분** / **손실 = 위 재생산 대기**. → 기존 "회수 귀환" 메커닉의 가치가 극대화. 무모한 자폭은 다음 판을 하급 기체로 뛰게 만든다(자연스러운 실패 페널티).
- 입고는 오프라인 중에도 진행. 접속 강요 없음.
- **재고 0이어도 T1으로 모든 미션 출격 가능** — 다만 보상 배율과 공략 난이도에서 손해. 벽이 아니라 리듬.
- 서사적 정당화: "생산 라인이 전선을 못 따라간다"는 이 전쟁의 실제 조건. 소린 장관 무전으로 설명.

#### 6.6.2 입고 단축 수단 (수익 접점)

| 수단 | 내용 | 비고 |
|---|---|---|
| **전과 보급** | 미션 ★3 클리어·주간 쿼터 달성 시 즉시 입고 1~2기 | **잘하면 기다릴 필요가 없다** — 실력이 시간을 대체 |
| **긴급 보급 요청(광고)** | 리워드 광고 1회 = 즉시 입고 1기, 일 2회 한도 | |
| **보급 우선권(IAP 구독)** | 입고 시간 -50%, 일일 즉시입고 +2, 광고 제거 | 시간만 사는 것 — 전용 장비·성능 판매 없음(P2W 아님) |

→ 핵심: **유료는 "시간"만 판다. 성능과 콘텐츠는 전부 무료 획득 가능.**

#### 6.6.3 플랫폼별 적용

- **모바일**: 재고제 적용.
- **Steam**: 재고제 **완전 비활성화**(단일 구매 프리미엄). 동일 코드에서 플래그로 분기 — 설계 단계부터 분리해 둘 것.

### 6.7 난이도 배율 보상

같은 미션도 **스스로 어렵게 만들면 더 준다.** 4.5 위협 카탈로그를 자발적 옵션으로 재활용 — 콘텐츠 추가 비용 0으로 리플레이 가치 생성.

#### 6.7.1 배율 구성 (합산 후 기본 보상에 곱연산, 상한 ×2.5)

| 구분 | 배율 | 조건 |
|---|---|---|
| 차수 기본 | ×1.0 / ×1.4 / ×1.8 | 1·2·3차수 |
| **위협 추가(자발)** | 각 +0.2 (최대 3개) | 출격 전 옵션에서 위협 선택 활성화 (예: 야간 강제, 재밍 추가, 산탄총 분대 증원) |
| ACRO 매뉴얼 조종 | +0.2 | 어시스트 해제 |
| 하급 기체 도전 | +0.3 | 권장 티어보다 낮은 기체로 클리어 |
| 노히트 | +0.3 | 피탄 0 |
| 기체 회수 귀환 | +0.2 | 자폭 없이 복귀(정비 5분 혜택과 중복) |
| 시간 제한 달성 | +0.2 | 미션별 목표 시간 |

#### 6.7.2 설계 규칙

1. **배율 선택은 출격 전에 확정** — 클리어 후 소급 금지(도박화 방지).
2. **실패해도 페널티 없음** — 도전 실패 시 기본 보상만. 시도 자체를 벌하지 않는다.
3. **UI 표기**: 로드아웃 하단에 `보상 배율 ×1.8` 실시간 표시 + 활성 위협 아이콘 나열.
4. **작전 요청(일일)에도 적용** — 파밍 효율을 실력으로 단축할 수 있게. 시간을 실력으로 사는 구조가 6.6과 짝을 이룬다.

## 11. 수익화

**대원칙: 유료는 "시간"만 판다. 성능·콘텐츠는 전부 무료 획득 가능.**

| 형태 | 내용 |
|---|---|
| 리워드 광고 | 긴급 보급 요청(즉시 입고 1기, 일 2회), 작전 요청 리롤, SP 1.5배 부스트 |
| **보급 우선권** (구독) | 입고 시간 -50%, 일일 즉시입고 +2, 광고 제거. 월 정기 |

| 스킨/도색 팩 | 성능 무관 외형만 (기체 도색, OSD 테마) |

**금지**: 성능 P2W 판매 금지 — 장비는 반드시 플레이(SP)로만. 확률형 유료 상자 금지. FOMO 타이머 금지. 밀리터리 코어 유저층은 이 셋에 극도로 민감하며, Steam 확장 시 치명적.

**Steam 버전**: 단일 구매 프리미엄($10~15). 재고제·광고·구독 전부 비활성화 (6.6.3 플래그 분기).
