# 내러티브 설계서 v0.1 — 「SIGNAL LOST: FPV」

> GDD v0.2 / 개발 설계서 v0.1 연계 문서
> 원칙: ① 국가명·실존 인물 추상화(심사 리스크 회피) ② 텍스트 무전만으로 전달(성우·컷신 비용 0) ③ 모든 문자열은 첫 줄부터 로컬라이즈 키로 작성

## 1. 세계관 (가공 설정)

- 배경: 가상 국가 **"베리스카 공화국"**이 북쪽 대국 **"연방"**의 침공을 받아 3년째 소모전 중. 동부 전선은 참호와 드론의 전장이 됐다.
- 시대감: 현대전 페러다임 전환기 — 포병의 시대가 저물고 "천 달러 드론이 천만 달러 장비를 잡는" 시대.
- 플레이어: 징집 3주차 신병 **콜사인 "루키(Rookie)"**. 원래 직업은 배달 라이더 — 드론 조종 감각이 있다는 이유로 속성 교육 후 즉시 전선 투입. (플레이어 이름은 입력받지 않고 콜사인 고정 → 로컬라이즈 단순화)
- **핵심 정서**: 영웅 서사가 아니라 "화면 너머의 전쟁". 플레이어는 참호에 없다. 지하 벙커의 모니터 앞에 있다. 죽는 건 기체지만, 화면이 꺼질 때마다 심장이 내려앉는다.

## 2. 등장인물 (전원 무전 텍스트로만 등장)

| 캐릭터 | 역할 | 성격/문체 | 모티프 |
|---|---|---|---|
| **소린 장관** (34세) | 국방혁신부 신임 장관 | 스타트업 창업자 출신. 짧고 데이터 중심 화법. "실적이 곧 보급이다." 주간 쿼터 공지·티어 승급 메시지 담당 | 젊은 디지털 장관 |
| **바딤 상사** (48세) | 드론 중대 선임 조종사, 플레이어의 사수 | 구식 군인. 처음엔 "게임하다 온 애송이"라고 무시 → 실적 쌓일수록 인정. 브리핑·전술 조언 담당. 거칠지만 정 있는 문체 | 베테랑 교관 |
| **"고스트"** | 정찰 드론 운용병 (얼굴 없음) | 확인 킬 촬영 담당. 짧은 무전만. "확인했다. 잘 가라, 고철." | BDA 파트너 |
| **소콜 중대장** | 중대 지휘관 | 미션 승인·긴급 명령. 사무적 | 지휘 계통 |

**관계 아크**: 바딤의 태도 변화가 플레이어 성장의 거울. T1 "애송이" → T3 "루키" → T5 "…네가 내 사수보다 낫다." 이 한 줄을 위해 전체를 쌓는다.

## 3. 스토리 구조 — 3막 구성 (캠페인 = 챕터)

실전 전개를 그대로 서사화: **1막 "배운다" → 2막 "당한다" → 3막 "끊고, 민다"**. 특히 3막은 실제 "병참 봉쇄(중거리 타격으로 적 보급을 말려 죽이는 전략)"를 게임의 대반격 서사로 채택 — 플레이어의 격파 하나하나가 전선 지도에 반영되는 구조.

### 【1막 — 배운다】 "화면 너머의 전쟁"

**프롤로그 — "모니터 앞의 전쟁"** (튜토리얼)
징집 통지 → 3주 속성 교육(= 조작 튜토리얼, 링 코스) → 첫 배치 날 소린 장관의 전군 방송:

> **[전군 공지 — 국방혁신부]**
> "오늘부로 보급 체계를 바꿉니다. 연공서열도, 서류도 아닙니다. **격파를 증명하면, 장비가 갑니다.** 여러분의 화면이 곧 보급창구입니다. — 장관 소린"

바딤: "장관이라는 게 나보다 어려. …그래도 저 말은 맞다. 여기선 증명한 놈만 산다. 가자, 애송이."

**Ch.1 — 들판의 추격전 (M2)** : 첫 실전. 트럭 하나 잡고 손이 떨리는 경험. 확인 킬 시스템 학습.
**Ch.2 — 지하의 침묵 (M6)** : 참호전의 현실. 바딤의 과거(포병 출신 — "포가 왕이던 시절" 회고, 드론에 부대를 잃은 과거 암시) 첫 단서.
**Ch.3 — 숨은 포탑 (M3)** : "죽이지 않는 임무". *열린 곳에 있으면, 보이고 있는 것이다* — 현대 전장의 제1원칙을 배움. 정찰병 SP 불만 → 장관의 정찰 SP 상향 응답(라이브 밸런싱을 내러티브로 소화).

### 【2막 — 당한다】 "하늘은 우리 것만이 아니다"

**Ch.4 — 검은 새벽 (M8, 신규: 기지 방공전)** : 적의 자폭 드론 편대가 야간에 아군 발전 시설·기지를 노리고 몰려온다. 플레이어는 **요격 드론(인터셉터)**으로 전환해 공중에서 적 드론을 직접 들이받아 격추 — 첫 드론 대 드론 공중전.
- 서사 포인트: 처음으로 "공격받는 쪽"이 됨. 모니터 룸이 정전되고 비상 발전기 소리 속에서 출격. 바딤: "네가 쏘던 화면 속 놈들도, 매일 밤 이 소리를 들었겠지."
- 실전 모티프: 요격 드론이 값비싼 방공 미사일을 대체하며 대량 생산·배치되는 실제 흐름.

**Ch.5 — 산탄총의 사정거리 (M7)** : 적 보병도 진화한다 — 대드론 산탄총, 배낭형 휴대 재밍기(참호급 전자전). 첫 '지는 느낌', 기체 연속 손실. 바딤: "기체는 사도 되는데, 감은 못 산다. 침착해."
**Ch.6 — 실 끊기 (M5)** : 재밍 불능의 적 광섬유 드론 등장 — 기술 군비 경쟁의 정점. **아군 오사(드론 프래트리사이드) 서브플롯**: 통신 두절로 이웃 중대가 아군 정찰기를 격추하는 사건 → "식별 먼저, 격발은 나중" 교훈 미션. 아군도 광섬유 도입(T5 장비 언락 동기화).

### 【3막 — 끊고, 민다】 "병참 봉쇄 작전"

2막 말미, 소린 장관의 전략 브리핑으로 막 전환:

> **[작전 지시 — 국방혁신부]**
> "적 전선이 단단한 건 참호가 아니라 그 뒤의 도로 때문입니다. 연료차, 탄약 트럭, 보급 열차. **보급을 끊으면 참호의 적은 식량도, 탄약도, 야시경도, 배터리도 없습니다.** 오늘부터 '자물쇠 작전'을 개시합니다. 전선 뒤 30~180km — 이제 그들의 후방은 없습니다."

**Ch.7 — 도로 사냥꾼 (M9, 신규: 보급 차단전)** : 중계 드론을 띄우고 장거리 개조 기체(윙 키트 장착 — 장비 언락과 동기화)로 적 후방 보급로 상공을 배회하며 연료 트럭·보급 종대를 요격. 미션 성공이 누적될수록 **전선 상황판(맵)에 적 보급 상태 게이지가 실시간으로 말라감** — "내 격파가 전선을 민다"를 시각화하는 핵심 장치.
- 서사 포인트: 고스트의 정찰 화면에 굶주린 적 진지가 잡힘. 바딤: "포로 심문 내용 들었나? 사흘째 탄약 배급이 없었다더라. …네가 한 거다."

**Ch.8 — 값비싼 새들 (M1)** : 보급 차단으로 적 방공망이 후방으로 물러난 틈 — 비행장 타격의 전제 조건이 3막 서사로 자연스럽게 성립. 성공 후 소린 장관 직접 무전: "다음 작전, 네 화면으로 하고 싶다."
**Ch.9 — 트럭의 새벽 (M4, 피날레)** : 적 종심 침투 특수작전, 4기 릴레이. 보급이 끊긴 적 전선이 무너지고 아군이 전진하는 무전이 배경에 흐른다. 엔딩:

> 바딤: "루키. 아니, — 이젠 콜사인 바꿔라. 네가 사수다."
> (크레딧: 마지막 드론의 귀환 비행 화면 위로, 수복된 마을의 불빛)

**차수(2·3차)의 내러티브**: 동일 챕터 상위 차수는 "같은 구역, 악화된 상황" 재파병 형식 — 신규 대사는 브리핑 2~3줄이면 충분. 저비용 원칙 유지.

### 3.1 신규 미션 요약 (GDD 3장에 반영 필요)

| 미션 | 유형 | 핵심 메커닉 | 대응 실전 사례 |
|---|---|---|---|
| **M8 검은 새벽** | 기지 방공 (요격전) | 요격 드론으로 적 자폭 드론 공중 격추. 열원 추적 시점, 충돌 요격 타이밍 게임. 웨이브 방어 형식 → 반복 플레이 적합(작전 요청 축에도 활용) | 야간 자폭 드론 공습 vs FPV 인터셉터 대량 운용 |
| **M9 도로 사냥꾼** | 보급 차단 (배회 요격) | 중계기 운용 + 장거리 배회 → 도로 위 이동 표적 선별 타격. 표적 가치 판단(연료차 > 트럭 > 승용차, 민간 차량 오폭 = 대형 페널티) | 전선 후방 30~180km 병참 차단 캠페인, 연료 트럭·열차 요격 |

### 3.2 랜덤 무전 이벤트 풀 (몰입 장치, 작전 요청 축에서 재생)

미션 중 낮은 확률로 발생하는 1~2줄 무전 — 전장이 살아있다는 감각을 만드는 저비용 장치:

- **아군 오사 경보**: "전 채널 주의 — B중대 구역에 아군 정찰기 활동 중. 식별 확인 후 격발." (실제 양측 모두 겪는 드론 오사 문제 반영)
- **적 요격 드론 접근**: "레이더 접촉 — 네 6시 방향, 적 인터셉터로 추정. 고도 낮춰라." → 실제 회피 기동 필요 (M8 습득 기술의 역방향 활용)
- **보급 대박**: "그 트럭, 적재물 유폭 확인. 탄약 수송이었다. 보너스 SP 승인."
- **재밍 급증 경보**: "K-구역 전자전 활성 — 신호 품질 저하 예상. 광섬유 기체 권장." (signalQuality 변수와 연동)
- **고스트의 한 마디**: "…오늘 세 번째다. 잘 가라, 고철."

## 4. 대사 샘플 (브리핑 포맷 규격)

모든 브리핑은 동일 규격 — UI 구현·번역 관리가 쉬워짐:

```
[발신: 바딤 상사]                      ← speaker
■ 작전명: 강철 사냥                    ← title
■ 상황: 연방군 장갑 종대가 K-7 도로로 남하 중.   ← situation (2줄 이내)
■ 임무: 선두 차량 포함 2대 격파. 종대를 세워라.  ← objective
■ 조언: 놈들 뒤를 잡아라. 정면은 기관총이 본다.  ← tip (전술 힌트 = 게임성 가이드)
"배터리 아끼지 마라. 아낀 배터리로 관 짜는 꼴 본다."  ← flavor (캐릭터 한 줄)
```

무전 인게임 연출: 미션 중 트리거 대사는 화면 하단 1줄, 3초 표시, 로그에 누적. 음성 없음 — 무전 비프음 + 텍스트 타이핑 효과만.

## 5. 로컬라이제이션 스펙 (다국어)

### 5.1 지원 언어 (우선순위)

| 순위 | 언어 | 근거 |
|---|---|---|
| 1차 (v1.0 출시) | **영어(EN)** | 기본 언어. 원문은 한국어로 쓰되 배포 기준 언어는 EN |
| 1차 | **한국어(KO)** | 개발 원문 |
| 1차 | **우크라이나어(UK)** | 장르 핵심 커뮤니티. 유사 게임 유저 절반이 해외 — 진정성 마케팅 효과 큼 |

| 보류 | 러시아어(RU) | 소재 특성상 커뮤니티 리스크 검토 후 결정 |

### 5.2 기술 구조 (Unity)

- **Unity Localization 패키지** 사용. String Table 기반.
- 키 네이밍 규칙: `story.ch1.brief.title`, `story.ch1.brief.situation`, `ui.osd.battery`, `item.frame.sparrow7.name`, `minister.quota.weekly.001`
- 코드에 문자열 하드코딩 **절대 금지** — 개발 설계서 8장 코딩 규약에 추가.
- 폰트: 라틴+키릴+한글+일본어 커버 필요 → **Noto Sans** 패밀리(무료) TMP 폰트 에셋으로 언어별 분리 로드 (메모리 절약).
- OSD 등폭 폰트도 키릴 지원 확인 필수 (JetBrains Mono는 키릴 OK).
- 소스 오브 트루스: `Localization/strings_master.csv` (key, ko, en, uk, ...) — Git 관리, Unity로 임포트.

### 5.3 번역 워크플로우 (1인 개발 최적화)

```
1. 한국어 원문 작성 (이 문서 + 이후 대사 시트)
2. Claude로 EN 번역 + 톤 가이드 적용 ("군용 무전체, 짧게, 계급 호칭 유지")
3. EN을 피벗으로 UK/PL 등 번역 (군사 용어 정확도는 EN 기준이 안전)
4. 언어별 검수 포인트: 우크라이나어는 출시 전 원어민 검수 1회 권장
   (커뮤니티 민감도가 가장 높은 언어 — 오역 시 역효과)
5. 문자열 길이 규칙: UI 버튼 텍스트는 EN 기준 +30% 여유 폭 설계 (독일어 폭발 대비)
```

### 5.4 문화 로컬라이즈 주의점

- 캐릭터 이름(소린/바딤/고스트)은 전 언어 공통 표기 — 음차만.
- 날짜/단위: 미터법 고정 (군사 표준), 시간 24h 고정 → 로케일 분기 불필요.
- 유머/거친 표현: 바딤 대사의 욕설 수위는 스토어 등급(16+) 내 유지, 언어별 강도 통일.
