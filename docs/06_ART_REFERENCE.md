> 목적: 추측이 아닌 실제 화면 특성을 셰이더 파라미터·HUD 규격·에셋 스펙으로 환산

## 1. 화면 톤 분석 (가장 중요한 발견)

### 1.1 열화상(백열, White-hot) — 캡처 1·2·3·6

기존 우리 셰이더의 열화상 구현이 **틀렸다.** 실제는 훨씬 극단적인 대비를 가진다.

| 요소 | 실측 밝기(정규화) | 비고 |
|---|---|---|
| 하늘 | **0.02~0.08 (거의 순흑)** | 상단 1/3이 완전히 검음 — 이게 열화상의 시그니처 |
| 지평선 대기층 | 0.35~0.5 (밝은 띠) | 하늘과 지면 사이 밝은 그라데이션 밴드 |
| 지면/모래/콘크리트 | 0.55~0.80 | 낮 동안 축열되어 밝게 |
| 수면(항만·강) | 0.10~0.20 (어두움) | 물은 차갑다 = 어둡다. **지형 판별의 핵심 단서** |
| 식생/수목 | 0.30~0.45 (중간 회색) | |
| 인원·차량 엔진 | 0.92~1.0 (백열) | 소형이지만 최대 밝기로 튐 |
| 건물 지붕 | 0.65~0.85 | 창문 격자가 어두운 점으로 보임 |

**핵심 규칙**: 열화상은 "흑백 반전"이 아니라 **"하늘=검정, 물=검정, 지면=밝음, 열원=백열"**의 4단 구조. 이것만 지켜도 진짜처럼 보인다.

### 1.2 주간 컬러(아날로그) — 캡처 4·5

- 채도가 매우 낮음 (원본 대비 40~50% 수준). 녹색 식생조차 회녹색으로 탈색.
- 대비도 낮고 하이라이트가 뭉개짐(클리핑). 그림자는 완전히 검게 죽지 않고 들려 있음.
- **모션 블러가 강함** — 고속 기동 시 지면이 흐름.
- 압축 아티팩트가 상시 보임.

### 1.3 압축 매크로블록 (우리가 놓친 요소)

캡처 2의 좌측 가장자리에 **8×8 픽셀 단위 사각 블록 노이즈**가 뚜렷하다. 이건 아날로그 노이즈가 아니라 **디지털 영상 압축 깨짐**이다. 현대 드론 영상의 진짜 질감은 이것.

→ 셰이더에 신규 효과 추가 필요: `blockGlitch` — 신호 품질 저하 시 UV를 8×8 블록 단위로 양자화하고 랜덤 오프셋. 기존 라인 지터보다 훨씬 "요즘 드론 영상" 같다.

## 2. HUD 규격 (실제 화면 그대로 채용)

우리 프로토타입 HUD는 너무 "게임적"이었다. 실제는 훨씬 **비대칭적이고 성긴** 배치.

```
┌──────────────────────────────────────────────┐
│ READY                            [⌐]     [¬] │  ← 좌상: 상태 텍스트만 (READY/AIR)
│ AIR                                          │     우상: 부대 엠블럼 2개 (코너 브래킷 안)
│                                              │
│      ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─         │  ← 점선 수평 가이드 (수평선 지시)
│                    ┼                         │  ← 중앙 십자선도 점선 조각
│                   (점선)              ALT 23m│  ← 우측 중하단에 고도
│                                        5  19 │  ← 그 아래 보조 수치 2개
│                                              │
│ PIKATES                                      │  ← 좌하단: 부대/조종사 콜사인
└──────────────────────────────────────────────┘
```

**채용할 원칙 5가지**
1. **모든 선은 점선(dashed)** — 실선 프레임 없음. 중앙 십자도 4조각 점선.
2. **텍스트는 코너에 흩어짐** — 좌상(상태), 우중하(고도/수치), 좌하(콜사인). 우리처럼 좌상에 몰지 않는다.
3. **배경판·테두리 상자 없음** — 텍스트에 얇은 검정 외곽선만.
4. **코너 브래킷** `[⌐] [¬]` 로 엠블럼/아이콘을 감싼다 → 우리 UI 컴포넌트 규격에 추가.
5. 수치는 라벨 없이 숫자만 나열되기도 함(`5 19`) — 정보 밀도보다 "실기 느낌" 우선.

### 2.1 표적 지시 오버레이 (신규 — 반드시 넣을 것)

캡처 1·3·4에서 확인된 **AI 표적 지정 UI**. 이건 우리 "AI 락 보조 모듈"의 시각적 정답이다.

| 상황 | 표현 |
|---|---|
| 원거리 다중 표적(캡처 1·3) | **녹색 가는 실선**이 화면 상단에서 표적까지 사선으로 뻗음 + 끝에 작은 다이아몬드/원 마커. 표적 옆에 짧은 영문 라벨(FUEL, FIRE 등) |
| 근거리 락온(캡처 4) | **황색/주황 사각 박스 + 내부 십자**. 박스가 표적 크기에 맞춰 스케일. 옆에 작은 태양형 아이콘 |
| 미확인 접촉 | 마커만 표시, 라벨 없음 |

→ 색 규칙: **녹색 = 원거리 지시/식별 완료**, **황색 = 근거리 락온/교전 준비**. 우리 팔레트(`text.primary` 녹색, `accent.amber` 황색)와 정확히 일치. 운이 좋다.

## 3. 환경 에셋 스펙 (캡처에서 직접 확인된 것만)

| # | 대상 | 관찰된 형태 | 로우폴리 제작 노트 |
|---|---|---|---|
| E1 | **철도교** (캡처1) | 다중 교각(4개) + 상판, 하천 횡단, 옆에 제방 도로 | 박스 6~8개 조합. 교각 사이 간격이 시각적 리듬 |
| E2 | **철도 야드** | 평행 선로 다발, 화물열차 편성, 신호탑 | 선로는 텍스처, 열차는 박스 반복 |
| E3 | **방공 미사일 진지** (캡처2) | 모래주머니 원형 방벽 안에 발사대, 주변 흙더미 | 원통형 방벽 + 경사 발사대. 진지 = 원형 실루엣 |
| E4 | **항만 시설** (캡처3) | 원통형 연료탱크 다수, 갠트리 크레인, 창고, 계류 선박, 6층 관리동 | 원통+박스. 크레인은 게임의 수직 랜드마크로 유용 |
| E5 | **삼림 도로** (캡처5) | 2차선 포장로 + **백색 가드레일**, 양옆 밀집 수목, 경사면 | 가드레일이 도로 인식의 핵심 — 우리 프로토타입에 추가 |
| E6 | **수목선(treeline)** | 도로/들판 경계의 띠 형태 밀집 수목 | 은폐·매복 지형. 현재 프로토타입은 나무가 산발적 → 띠 형태로 재배치 |
| E7 | **차량류** | 군용 트럭(캡처5), 전차(캡처4), **쿼드바이크/ATV**(캡처6) | ATV는 소형 고속 표적 = 난이도 높은 신규 표적 타입 |

**프로토타입 즉시 반영 항목**: 가드레일 있는 도로, 띠 형태 수목선, 원통형 연료탱크, 물(어두운 열화상 대비용).

## 4. 신규 미션 소재 (캡처에서 도출)

> 번호 정정 (2026-08-26): 원래 M11~M13 으로 적혀 있었으나 GDD 가 M1~M9 라 **M10 이 비어 있었다.**
> 미션 ID(`m10.tier1`)가 저장 데이터 키가 되므로(05 문서 3장) 콘텐츠가 생기기 전인 지금 메운다.

### M10. 다리를 끊어라 — "철도교 차단" (캡처1)
- 실제 사례: 크림반도 점령지에서 철도교를 완전 파괴한 특수작전군 작전.
- **게임성**: 교각은 정확한 지점(하부 접합부)을 때려야 붕괴. 상판 명중은 손상만. 여러 소티로 같은 교각을 반복 타격하는 **누적 데미지 구조** → 타격 편대 시스템과 완벽히 맞물림.
- 성공 시 3막 보급 게이지에 대폭 반영 (열차 = 최대 물량 보급선).

### M11. 항만의 밤 — "연료 저장고" (캡처3)
- **게임성**: 원통형 연료탱크는 소이탄 특효, 유폭 연쇄. 단 크레인·전선 등 수직 장애물 밀집 → 저공 진입 시 충돌 위험. 물은 열화상에서 검게 보여 **거리감 상실** (고도 판단 어려움) = 신규 위협 C4.
- 표적 우선순위 판단: 연료탱크 vs 계류 선박 vs 크레인.

### M12. 야간 도로 — "고속 표적" (캡처6)
- 쿼드바이크/오토바이 등 **소형 고속 이동 표적**. 열화상으로만 식별 가능(백열 점 2개).
- 회피 기동이 불규칙 → 리드샷 난이도 최상. 짧고 강렬한 작전 요청용 미션으로 적합.

### 기존 미션 보강
- **M4 심장부 타격**: 방공 미사일 진지(E3)의 실제 형태 확보 — 모래주머니 원형 방벽. 의존 그래프의 "미사일 진지" 노드 비주얼 확정.
- **M2 추격전**: 가드레일 있는 산악 도로 + 트럭. 캡처5가 이 미션의 레퍼런스 이미지 그 자체.
